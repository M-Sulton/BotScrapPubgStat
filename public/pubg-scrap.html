PANDUAN SETUP DISCORD BOT & DEPLOY KE VPS HERMES

Langkah Memasukkan Bot ke Server Discord Kamu:

  1. Buka Discord Developer Portal:

    Buka discord.com/developers/applications dan login dengan akun Discord kamu.

  2. Buat Aplikasi Baru:

    Klik tombol "New Application" di pojok kanan atas, beri nama (misal: PUBG Steam Bot), lalu klik Create.

  3. Ambil Bot Token:

    Di menu sebelah kiri, klik tab Bot. Klik "Reset Token" lalu Copy token tersebut. (PENTING: Masukkan token ini ke tombol Pengaturan di web ini!)

  4. Aktifkan Privileged Gateway Intents (WAJIB):

    Masih di tab Bot, scroll ke bawah ke bagian Privileged Gateway Intents. Centang/Aktifkan:

    • ✅ MESSAGE CONTENT INTENT (Wajib agar bot bisa membaca command chat)
    • ✅ SERVER MEMBERS INTENT

    Lalu klik Save Changes.

  5. Undang Bot ke Server Discord:

    Di menu kiri klik OAuth2 → URL Generator.

    Pada kolom SCOPES, centang: bot & applications.commands.

    Pada kolom BOT PERMISSIONS, centang: Send Messages, Embed Links, Read Message History, Attach Files.

    Copy link URL di paling bawah, buka di browser, lalu pilih Server Discord kamu & klik Authorize!

  6. Ambil Channel ID Discord:

    Buka Discord App → User Settings → Advanced → aktifkan Developer Mode.

    Klik kanan channel Discord tempat bot akan mengirim laporan jam 6 sore → pilih Copy Channel ID.

    Tempel Channel ID tersebut ke Pengaturan di website ini!
